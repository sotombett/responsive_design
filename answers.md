1. **Что такое Viewport meta tag и почему он важен для адаптивного дизайна?**

Это мета-тег <meta name="viewport" content="width=device-width, initial-scale=1.0">, который сообщает браузеру, как управлять размерами страницы и масштабированием. Он критически важен, так как без него мобильные браузеры отображают страницу в десктопном масштабе, а затем сжимают её, делая текст нечитаемым.


2. **Какие основные подходы к созданию адаптивных макетов вы использовали в работе (Fluid, Adaptive, Responsive)?**

В работе использовался подход Responsive (отзывчивый), который сочетает в себе гибкие сетки (Fluid) на основе процентов и медиа-запросы для изменения макета на разных брейкпоинтах. Также применялись относительные единицы измерения (rem, vw) и функция clamp().


3. **Как работает Mobile First подход и в чем его преимущества перед Desktop First?**

Mobile First — это проектирование сначала для мобильных устройств (маленьких экранов), а затем добавление стилей для более крупных экранов с помощью min-width. Преимущества: приоритет отдается основному контенту, страница быстрее загружается на мобильных устройствах, и проще масштабировать интерфейс вверх.


4. **Какие единицы измерения наиболее предпочтительны для адаптивной верстки и почему (%, rem, em, vw/vh)?**

- rem — для шрифтов и отступов (привязка к корневому элементу, легко масштабировать).
- % — для ширины контейнеров и сеток (гибкость).
- vw/vh — для элементов, зависящих от размера окна просмотра.
- em — для компонентов (зависит от размера шрифта родителя).


5. **Как функция clamp() помогает создавать адаптивную типографику?**

clamp(MIN, VAL, MAX) позволяет задать размер шрифта, который будет плавно масштабироваться в зависимости от ширины экрана (VAL), но не будет меньше MIN и больше MAX. Это избавляет от необходимости писать множество медиа-запросов для шрифтов.


6. **Какие основные брейкпоинты вы использовали и как определили эти значения?**

Использовались брейкпоинты: 1024px (планшеты), 768px (мобильные), 480px (маленькие мобильные). Эти значения взяты из стандартных разрешений популярных устройств и являются точками, в которых макет начинает ломаться или выглядеть неоптимально.


7. **Как медиа-запросы @media помогают создавать адаптивные стили? Приведите пример синтаксиса.**

Медиа-запросы применяют CSS-правила только при выполнении определенных условий (ширина, высота, ориентация экрана).
Пример: @media (max-width: 768px) { .nav-menu { display: none; } }.


8. **В чем разница между max-width и min-width в медиа-запросах и когда использовать каждый?**

max-width применяет стили для экранов до указанной ширины (подход Desktop First). min-width применяет стили для экранов от указанной ширины и больше (подход Mobile First). В современной разработке предпочтительнее min-width.


9. **Как сделать изображения адаптивными и какие CSS-свойства для этого используются?**

Чтобы изображения не выходили за пределы контейнера, используются свойства: max-width: 100%; и height: auto; (либо display: block; для удаления лишних отступов). Также можно использовать атрибут srcset для загрузки разных изображений под разные экраны.


10. **Какие инструменты браузера помогают тестировать и отлаживать адаптивный дизайн?**

Встроенные инструменты разработчика (DevTools): режим адаптивного дизайна (Device Mode / Responsive Design Mode), где можно эмулировать различные устройства, менять разрешение экрана, проверять работу медиа-запросов и скорости загрузки (Lighthouse).
